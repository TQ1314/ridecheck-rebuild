RIDECHECK TITLE & TRANSFER READINESS WORKFLOW

Goal:
Add a Title & Transfer Readiness section into the existing RideChecker inspection workflow.

This should NOT overhaul the inspection flow.
It should become a required workflow section near VIN / document verification.

Purpose:
RideCheck should help buyers identify transfer-document risks before they hand over money.

RideCheck is NOT providing legal advice, DMV services, notary services, or ownership guarantees.
RideCheck is documenting visible title/transfer readiness indicators only.

════════════════════════════════════
PHASE 3 — TRANSFER READINESS LOGIC
════════════════════════════════════

Create:

/lib/risk-intelligence/title-transfer-check.ts

Export:

calculateTransferReadiness(input)

Logic:

Start with status = ready.

Set status = concern if any of these are true:

- title_present = false
- vin_matches_title = false
- open_title = true
- lien_release_present = false when lien is indicated
- seller_name_on_title missing/unverified
- odometer_disclosure_completed = false when applicable

Set status = caution if:

- buyer_name_completed = false
- title_signed = false
- state_of_title = Other
- any required field = unable_to_verify

Risk flags:

TITLE_NOT_PRESENT
VIN_TITLE_MISMATCH
OPEN_TITLE
SELLER_NAME_UNVERIFIED
ODOMETER_DISCLOSURE_INCOMPLETE
LIEN_RELEASE_MISSING
TITLE_UNSIGNED
OUT_OF_STATE_TITLE
BUYER_NAME_NOT_COMPLETED
UNABLE_TO_VERIFY_DOCUMENTS

Return:

{
  transferReadinessStatus,
  riskFlags,
  summary
}

════════════════════════════════════
PHASE 4 — API ROUTES
════════════════════════════════════

Create or update:

POST
/api/ridechecker/orders/[orderId]/title-transfer-check

GET
/api/ridechecker/orders/[orderId]/title-transfer-check

Rules:
- Must require authenticated RideChecker assigned to the order OR ops/admin
- Must require payment authorization OR payment override
- Save checklist data
- Run calculateTransferReadiness()
- Store result in vehicle_title_transfer_checks

If unpaid and no override:
Return HTTP 402:
"Payment is required before title transfer review can be submitted."

════════════════════════════════════
PHASE 5 — RISK INTELLIGENCE INTEGRATION
════════════════════════════════════

Update overall risk scoring.

If transfer_readiness_status = ready:
+0

If caution:
+8

If concern:
+20

Hard escalation:
If VIN_TITLE_MISMATCH or OPEN_TITLE or TITLE_NOT_PRESENT:
overall transaction risk must be at least elevated.

If lien release missing when lien is indicated:
overall transaction risk must be at least elevated.

PHASE 6 — REPORT INTEGRATION
════════════════════════════════════

Add buyer-facing report section:

TITLE & TRANSFER READINESS

Display:

- Title present
- VIN matches title
- Seller name consistency
- Buyer name completed
- Odometer disclosure completed
- Lien release present
- Title signed
- Open title indicator
- State of title
- Transfer readiness status

Statuses:

GREEN:
Ready

YELLOW:
Caution

RED:
Concern

GRAY:
Unable to verify

Safe wording:

"RideCheck reviewed visible title/transfer indicators provided at the time of inspection."

"RideCheck does not verify legal ownership, guarantee transferability, provide notary services, or replace DMV/title verification."

"Transfer concern identified. Buyer should verify title status with the appropriate state motor vehicle authority before completing purchase."

Do NOT say:

- Seller is not the owner
- Title is fraudulent
- Vehicle cannot be transferred
- Buyer should or should not buy
